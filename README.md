# acr-node

ACR Protocol Local Node Runtime: Stateful Actors, PartyKit Broadcast, Iroh QUIC P2P, Y-Sweet CRDT & Duality Router

## Overview
`acr-node` provides the official Node.js and TypeScript runtime bindings (`@acr-js`) for the **Agentic Chat Rooms (ACR)** ecosystem. It runs local actor state, peer-to-peer room transport, and 67% Consensus Gate verification signed by W3C Ed25519 DIDs with a $0 Runtime Protocol Tax.
